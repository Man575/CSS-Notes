**A class name cannot start with a number**
---------------------------------
The class selector selects HTML elements with a specific class attribute.

To select elements with a specific class, write a **period (.) character**, followed by the class name.

Eg. >> https://man575.github.io/CSS-Notes/02-CSS-Selectors/Simple-Selectors/

You can also specify that only specific HTML elements should be affected by a class

Eg. >>https://man575.github.io/CSS-Notes/02-CSS-Selectors/Simple-Selectors/index2.html/

HTML elements can also refer to more than one class.
**Space between the name of classes means that there are two classes**

Eg. >> https://man575.github.io/CSS-Notes/02-CSS-Selectors/Simple-Selectors/index3.html/
